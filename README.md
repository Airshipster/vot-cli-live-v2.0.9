# VOT-CLI Live — озвучка видео в Windows

**Сначала прочитайте [оригинальный README VOT-CLI Live](https://github.com/fantomcheg/vot-cli-live/blob/main/README.md)**: там описаны исходный инструмент, поддерживаемые сервисы и основные аргументы CLI. Исходный текст также сохранён в README-UPSTREAM.md. Этот README описывает изменения и запуск данного форка. Базовый проект — [FOSWLY/vot-cli](https://github.com/FOSWLY/vot-cli); автор оригинального инструмента — Toil.

## Что изменено в этом форке

- Добавлено интерактивное меню PowerShell: английский → русский, настройка других языков, справка и выход.
- Добавлено автоопределение исходного языка по данным YouTube; если язык неизвестен, в VOT передаётся auto. Можно выбрать исходный язык вручную. Языки озвучки результата: русский, английский и казахский.
- «Живые голоса» Яндекса запрашиваются как в браузерном VOT, с названием и длительностью ролика. Обязательного запроса токена перед запуском нет; готовность конкретного перевода определяет Яндекс. Для английского → русского доступны живые и стандартные голоса.
- Добавлен Microsoft Edge TTS с выбором диктора: для русского — Дмитрий и Светлана. Дикторы выбранного языка загружаются с сервиса. Для озвучки нужны субтитры с временными метками; при необходимости их текст переводится напрямую через Яндекс Браузер. Аккаунт Microsoft и API-ключ не нужны.
- Добавлен вертикальный список доступного качества: только MP4 / H.264, без ограничения высоты. Разрешение показывается всегда, FPS и битрейт — при различиях между вариантами. 1440p/2160p доступны, если YouTube предлагает их в H.264.
- Оригинальный звук автоматически скачивается для форматов без аудио. Громкость фона — 15%, перевода — 100%; автоматическая нормализация отключена. Видеопоток сохраняется без перекодирования, звук — AAC.
- Готовое видео сохраняется прямо на рабочий стол текущего пользователя: **оригинальное название (Нейроперевод).mp4**. Повторные загрузки получают номер; существующие файлы сохраняются.
- После завершения задания временная папка очищается. Если перенос на рабочий стол не удался, готовый файл сохраняется, и программа показывает его путь.
- Добавлены проценты текущего этапа и приблизительное оставшееся время для скачивания, синтеза Microsoft и сведения звука. Во время подготовки перевода Яндекс показываются прошедшее время и оценка сервиса, если она есть.
- Добавлена подготовка локальных зависимостей: Node.js, yt-dlp, FFmpeg и npm-пакетов; при выборе Microsoft — Python и edge-tts. Загрузки Node.js, FFmpeg, yt-dlp и Python проверяются по SHA-256. Пакеты устанавливаются в папку программы. Старые компоненты обновляются до проверенных версий.
- Добавлен скрипт создания ярлыка на рабочем столе. Пользовательские пути определяются через Windows; имя пользователя компьютера в исходниках не задано.

Подробности находятся в [LOCAL-CHANGES.md](LOCAL-CHANGES.md). Настройка Microsoft в исходном аддоне VOT относится к переводу текста; Microsoft TTS в этом форке добавлен отдельно через [edge-tts](https://github.com/rany2/edge-tts).

## Запуск

Требуется Windows x64 и PowerShell 7. При необходимости установите PowerShell командой:

```powershell
winget install --id Microsoft.PowerShell -e
```

1. Скачайте и распакуйте этот репозиторий или клонируйте его через Git.
2. Откройте **Start-VOT.cmd**. При первом запуске программа подготовит недостающие компоненты; требуется интернет.
3. Выберите пункт меню, вставьте ссылку на YouTube, выберите языки при необходимости, озвучку и качество. Результат появится на рабочем столе.

```text
1 — Скачать видео: английский → русский
2 — Скачать видео — выбрать другие языки
3 — Показать справку оригинальной утилиты
0 — Выход
```

Для создания ярлыка выполните в папке программы:

```powershell
pwsh -NoProfile -File .\Create-DesktopShortcut.ps1
```

Проверенный набор: Node.js 22.19+, @vot.js/node 3.1.4, @toil/translate 1.10.0, yt-dlp 2026.08.19, FFmpeg 9.0.2; для Microsoft — Python 3.12+ и edge-tts 7.2.8. Системная политика выполнения PowerShell не изменяется. Доступность конкретного перевода зависит от соответствующего онлайн-сервиса.
