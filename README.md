# VOT-CLI Live v2.1.0 — нейроперевод видео для Windows

**Прежде всего прочитайте [README исходного для нас VOT-CLI Live](https://github.com/fantomcheg/vot-cli-live/blob/main/README.md).** Его копия сохранена в [README-UPSTREAM.md](README-UPSTREAM.md). Здесь описаны возможности этого форка. [English overview](README-EN.md).

Укажите ссылку на YouTube или выберите видео на компьютере, затем язык, голос и качество. Программа создаст **`Название (Нейроперевод).mp4`** на рабочем столе текущего пользователя. Можно обработать один ролик, канал, плейлист или список ссылок.

## Происхождение и версия

1. [FOSWLY/vot-cli](https://github.com/FOSWLY/vot-cli) — исходная утилита; автор Toil / @ToilOfficial.
2. [fantomcheg/vot-cli-live](https://github.com/fantomcheg/vot-cli-live) — форк с «Живыми голосами» Яндекса и сборкой видео с переводом.
3. [Airshipster/vot-cli-live-v2.0.9](https://github.com/Airshipster/vot-cli-live-v2.0.9) — этот форк с меню Windows и возможностями ниже.

Текущая версия — **2.1.0 от 18 октября 2026 года**, на основе доработок до `2.1.0-local.19`. Число `v2.0.9` в адресе репозитория осталось от его создания. Форк может отставать от upstream; обновления исходных проектов автоматически не объединяются.

## Запуск

1. Установите **PowerShell 7**, если его нет:

   ```powershell
   winget install --id Microsoft.PowerShell -e
   ```

2. Скачайте ZIP этого репозитория, распакуйте в отдельную папку и откройте **`Start-VOT.cmd`**.
3. Выберите источник, язык, голос и качество. Дождитесь MP4 на рабочем столе.

Node.js, yt-dlp и FFmpeg проверяются при запуске; отсутствующие или неподходящие компоненты подготавливаются локально в `.tools`. Для Microsoft TTS отдельно подготавливаются Python и edge-tts, для локального видео — Cloudflare Tunnel. Эти зависимости не входят в репозиторий. Загрузки Node.js, yt-dlp, FFmpeg и cloudflared проверяются по контрольным суммам. Версии закреплены в скриптах: это не обновление до каждого нового релиза upstream. Системная политика выполнения PowerShell не изменяется.

Создать ярлык:

```powershell
pwsh -NoProfile -File .\Create-DesktopShortcut.ps1
```

Пути вычисляются через стандартные папки Windows. Имя профиля другого компьютера подставлять не нужно.

## Меню

```text
1 — Озвучить видео с YouTube
2 — Озвучить локальное видео
3 — Справка оригинальной утилиты
0 — Выход
```

В разделе **YouTube**: одно видео, канал целиком, список ссылок, продолжение очереди. В разделе **Локальное видео**: выбор файла через стандартное окно Windows и аккаунт Яндекса. Для сохранённого входа показываются состояние и удаление; предложение войти появляется, когда доступа нет.

## Языки и голоса

- По умолчанию — **на русский с автоматическим определением исходного языка**. Можно выбрать другую пару из поддерживаемых языков; доступность зависит от движка.
- **Яндекс — Живые голоса:** английский → русский. Вход используется, если сохранён; сервис может потребовать авторизацию. При отказе стандартный голос не подставляется незаметно.
- **Яндекс — Стандартные голоса:** запрос без аккаунта поддерживается, но доступность перевода определяется сервисом.
- **Microsoft Edge — нейронные голоса:** выбор диктора целевого языка, например Дмитрий или Светлана для русского. Нужны субтитры с временными метками; при необходимости текст переводится и озвучивается Edge TTS. Без подходящих субтитров режим может быть недоступен. Аккаунт Microsoft и платный API-ключ не требуются.

Для локальных «Живых голосов» нужен вход Яндекса. Программа использует доступ и для YouTube, когда сервис его требует. В репозитории нет готового входа: каждый пользователь авторизуется самостоятельно. См. [PRIVACY.md](PRIVACY.md).

## Каналы, плейлисты и списки

- Поддерживаются адреса каналов `@имя`, `/channel/…`, `/c/…`, `/user/…`, включая вкладки. Получаются доступные видео, Shorts и записи эфиров; текущие и предстоящие эфиры пропускаются.
- Для списка открывается окно Windows: вставьте блок ссылок или загрузите TXT/CSV/JSON/Markdown. Поддерживаются `watch`, `youtu.be`, `shorts`, `live`, `embed`, мобильные адреса, ссылки без `https://`, ID по строкам, каналы и плейлисты.
- Повторы убираются с сохранением порядка. Нераспознанные и недоступные адреса перечисляются отдельно.
- До запуска можно исключить номера/диапазоны: **`2, 5, 8-12`**. Enter оставляет все.
- Язык, голос, режим запросов и качество задаются один раз на очередь. Ролики обрабатываются **по одному**.
- **Продолжить очередь** повторяет незавершённые и неудачные задания. Готовые файлы пропускаются, если сохранились на месте; исключённые остаются исключёнными.

### Два режима запросов

| Режим | Когда запрашивается качество | Фрагменты | Пауза между роликами |
| --- | --- | --- | --- |
| **1 — Постепенный**, по умолчанию | Перед конкретным роликом; заранее только список | Последовательно | 10 секунд |
| **2 — С предварительной проверкой** | Сначала для всего списка, по очереди | В четыре потока | Без дополнительной паузы |

Приглашение: **«Выберите режим запросов (1 или 2; Enter — 1)»**. Режим сохраняется для продолжения. Старые очереди без этого поля используют прежнее поведение. Постепенный режим уменьшает интенсивность запросов, но не гарантирует отсутствие отказов YouTube или Яндекса. Разные ролики не обрабатываются одновременно в обоих режимах.

## Качество и звук

**Лучшее доступное качество каждого ролика** — вариант по умолчанию для очереди, без ограничения высоты. Можно задать верхнюю границу: при пределе 1080p ролик с максимумом 720p сохраняется в 720p.

- В постепенном режиме предлагаются пределы от 144p до 4320p с любой частотой кадров. Это настройки предела, а не заранее проверенная доступность.
- Предварительная проверка показывает объединённый список разрешений/FPS и число роликов с каждым вариантом. Ошибка запроса не считается отсутствием высокого качества. Если подтверждённое качество исчезло, список запрашивается повторно; при повторном расхождении ролик получает ошибку.
- В каждом размере **ширина × высота** сначала предпочитается **H.264**, затем среди оставшихся вариантов — **MP4**. Если их нет, используются альтернативы. Более высокое разрешение не скрывается только из-за VP9 или AV1.
- **«Отобразить все варианты»** отключает приоритеты. В одиночном видео показываются отдельные потоки; в очереди разрешения/FPS объединяются, поскольку ID и битрейты у роликов различаются.
- В одиночном видео свойства, включая FPS и контейнер, выводятся при различиях. Размер относится к исходному видеопотоку. У HLS скорость манифеста не равна измеренному среднему битрейту; разные цифры не обязательно означают разное изображение.

Оригинальный звук получается отдельно, если видеопоток не содержит его: **оригинал 15%, перевод 100%**, нормализация выключена. Результат — MP4 с AAC. Без обложки совместимый видеопоток копируется без повторного сжатия; исходный контейнер может отличаться от итогового.

### Обложка первым кадром

Введите **`4 000`**, чтобы выбрать вариант 4 и поставить превью YouTube первым кадром. **`4`** выбирает тот же вариант без обложки. Для очереди это применяется ко всем роликам.

Изображение вписывается без растяжения; меняется первый кадр, начало звука и длительность сохраняются. Видео перекодируется в H.264 с целевым средним битрейтом исходного видеопотока, измеренным по пакетам. Размер остаётся примерно прежним; точное совпадение байтов и отсутствие потери детализации не гарантируются. При переходе из VP9/AV1 в H.264 разница может быть заметнее. Для локального видео опция недоступна. Первый кадр не гарантирует выбор миниатюры самим YouTube после загрузки.

## Видео на компьютере

**Локальное видео → Выбрать видеофайл** открывает стандартное окно Windows. Оригинал сохраняется; программа подготавливает копию. Совместимые видеопотоки копируются, несовместимые преобразуются.

**Это онлайн-перевод локального файла, а не работа без интернета.** Яндекс получает выбранный ролик через локальный сервер и временный HTTPS-туннель Cloudflare. Аккаунт Cloudflare не нужен. Случайный путь открывает только выбранный файл, не другие папки. Полная ссылка даёт доступ к файлу, пока задание активно. После нормального завершения, ошибки или отмены сервер и туннель закрываются.

```powershell
pwsh -NoProfile -STA -File .\Run-VOT.ps1 -LocalVideo "C:\Videos\lesson.mp4"
```

## Прогресс и восстановление

- Скачивание и сведение показывают проценты и оценку времени. Ожидание перевода использует оценку сервиса, если доступна. В интерактивной консоли обновляется одна строка; при перенаправлении в файл сохраняется история.
- Очередь показывает **`[3/11]`**, общий процент, число готовых **`3/11`**, ошибки и остаток. Процент учитывает завершённые попытки, включая ошибки. Заставки, авторство и итог «всё завершено, 1/1» не повторяются после каждого ролика; в конце есть общий итог.
- После HTTP 401/403 при скачивании YouTube — один повтор через 30 секунд, с обновлением ссылок и последовательными фрагментами. Качество сохраняется. Постоянный отказ приостанавливает очередь; ошибка скачивания не выдаётся за потерю входа Яндекса.
- Для временного отказа самого перевода предусмотрены ограниченные повторы и один штатный запрос нового перевода. Ошибки авторизации этот механизм не обходит.
- Активная загрузка не прерывается общим десятиминутным таймером; сетевые тайм-ауты и повторы ограничены. Недоступные фрагменты не пропускаются для создания обрезанного «успешного» файла.
- Каждая попытка сохраняет JSONL. Его путь печатается как **«Диагностика: …»** и добавляется в отчёт. См. [DIAGNOSTICS.md](DIAGNOSTICS.md).

## Данные текущего пользователя

| Данные | Расположение |
| --- | --- |
| Готовые видео | Рабочий стол текущего пользователя |
| Временная обработка | `.work/video-jobs` рядом с программой |
| Очереди, отчёты, диагностика | `%LOCALAPPDATA%\VOT-CLI-Live` |
| Зашифрованный вход Яндекса | `%USERPROFILE%\.vot-cli-live\yandex-account.dpapi.json` |
| Зависимости и кэш | `.tools` рядом с программой |

После задания временная обработка очищается; после аварийного закрытия файлы могут остаться. При ошибке переноса готовый файл сохраняется для восстановления. Одноимённый результат не перезаписывается — подбирается свободное имя.

Очереди содержат ссылки, названия и пути ваших файлов. Не публикуйте их вместе с кодом. Токены не входят в поставку, защищаются в журналах и передаются дочерним заданиям через окружение. Перед отправкой отчёта проверьте содержимое. Подробнее — [PRIVACY.md](PRIVACY.md).

## Проверки и ограничения

До публикации выполнены реальные переводы YouTube и локального видео, проверка канала из 11 роликов с исправлениями и повторами, отдельный ролик в постепенном режиме. Проверялись длительность, разрешение, кодеки, декодирование и очистка временных файлов. Порядок очереди, интерфейс, паузы, продолжение, HTTP-ошибки и очистка тестовых секретов проверялись отдельно. Это не означает повторный полный прогон каждого сценария на окончательной версии или гарантию работы любого канала.

Нужен интернет. Приватные, удалённые и недоступные видео, ограничения сервисов и отсутствие субтитров могут помешать обработке. Программа не обещает обход авторизации или ограничений доступа.
