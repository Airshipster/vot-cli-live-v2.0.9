```bash
  -c:v copy -map 0:v:0 \
  -filter_complex "[0:a][1:a]amix=inputs=2:duration=first:dropout_transition=2:weights=0.3 1.5[m];[m]dynaudnorm=framelen=30:gausssize=31:maxgain=12[aout]" \

```

## 🎯 Ключевые улучшения

### 1. **Weights вместо Volume** 🔥
- Математически корректное микширование
- Меньше риска клиппинга (искажений)
- Автоматическая нормализация суммы весов

### 2. **Dynamic Audio Normalization** 🔥🔥🔥
- Автоматическое выравнивание громкости
- Не нужно крутить громкость во время просмотра
- Комфортное прослушивание

### 3. **Duration = First**
- Длительность по видео (правильно!)
- Не добавляет тишину в конце

### 4. **Dropout Transition = 2**
- Плавное затухание при обрыве дорожки
- Естественные переходы

## 🧪 Тестирование

### Автоматическое тестирование:
```bash
./test-audio-improvements.sh
```

### Ручное тестирование:

#### Тест 1: С нормализацией (по умолчанию)
```bash
node src/index.js --output="./test" --merge-video \
  "https://www.youtube.com/watch?v=jNQXAC9IVRw"
```
**Ожидаемый результат:**
- ✅ Видео создано
- ✅ Громкость ровная на протяжении всего видео
- ✅ Нет искажений звука

#### Тест 2: Без нормализации
```bash
node src/index.js --output="./test" --merge-video \
  --normalize-audio=false \
  "https://www.youtube.com/watch?v=jNQXAC9IVRw"
```
**Ожидаемый результат:**
- ✅ Видео создано быстрее (~10%)
- ⚠️ Громкость может скакать

#### Тест 3: Кастомные громкости
```bash
node src/index.js --output="./test" --merge-video \
  --original-volume=0.1 --translation-volume=1.5 \
  "https://www.youtube.com/watch?v=jNQXAC9IVRw"
```
**Ожидаемый результат:**
- ✅ Оригинал тихий (10%)
- ✅ Перевод громкий (150%)
- ✅ Громкость выровнена
