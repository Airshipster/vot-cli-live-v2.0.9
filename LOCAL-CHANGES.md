# Изменения форка — v2.1.0

18 октября 2026 года. База: [fantomcheg/vot-cli-live](https://github.com/fantomcheg/vot-cli-live), происходящий от [FOSWLY/vot-cli](https://github.com/FOSWLY/vot-cli), автор Toil / @ToilOfficial. Доработки до `2.1.0-local.19` объединены в эту публикацию.

## Добавлено после 2.0.9

- **Локальные видео:** стандартное окно выбора Windows, подготовка исходника, временный HTTPS-доступ только к выбранному файлу, сборка результата на рабочем столе.
- **Вход Яндекса:** обычная вкладка Chrome без аддона; локальный токен с DPAPI, состояние и удаление входа, передача доступа дочерним заданиям без записи в аргументы и очередь.
- **Каналы, плейлисты, списки:** разные формы YouTube-ссылок, импорт текстовых файлов, удаление повторов, исключение номеров/диапазонов, отчёт проблемных адресов.
- **Сохраняемая очередь:** обработка по одному, продолжение неудачных/незавершённых заданий, пропуск готовых результатов, блокировка одновременного запуска одной очереди.
- **Качество очереди:** лучшее для каждого ролика по умолчанию; предел разрешения/FPS, объединённый каталог при предварительной проверке и снятие фильтров. Ошибка запроса не считается отсутствием высокого качества.
- **Два режима запросов:** постепенный по умолчанию — качество перед роликом, один поток фрагментов, пауза 10 секунд; предварительная проверка — каталог до старта, четыре потока фрагментов. Режим сохраняется.
- **Передача исходной дорожки YouTube:** по запросу Яндекса скачивается полный исходный аудиофайл и передаётся через SDK; пустая дорожка не подставляется.
- **Ограниченное восстановление:** один повтор скачивания после HTTP 401/403 с обновлением ссылок и последовательными фрагментами; повторы временной ошибки перевода и один штатный запрос нового перевода. Авторизация не обходится.
- **Длинные загрузки:** снят общий десятиминутный таймер активной загрузки; сохранены сетевой тайм-аут, ограниченные повторы и отказ при недоступном фрагменте.
- **Диагностика:** JSONL на попытку, HTTP-коды отдельно от статусов Яндекса, этапы скачивания/передачи/сборки и итог. Секреты и адрес профиля Windows очищаются.
- **Интерфейс:** одна строка прогресса, общий счётчик вместо повторного «1/1», авторство один раз, единый финальный итог. Выбор режима явно показывает «1 или 2; Enter — 1».

## Сохранено из 2.0.9

Яндекс — стандартные и «Живые голоса»; Microsoft Edge TTS с выбором диктора; автоопределение/выбор языков; H.264 и MP4 в каждом размере; отсутствие искусственного предела 1080p; `000` для обложки первым кадром с измеренным средним битрейтом; оригинальный звук 15%, перевод 100%; готовый MP4 на рабочем столе и очистка временной обработки.

## Поставка

Исходники и документация. Входы, токены, Cookie, личные очереди, журналы, видео, кэши и зависимости не входят в поставку. Настройка выполняется на компьютере каждого пользователя. См. [README.md](README.md), [PRIVACY.md](PRIVACY.md), [DIAGNOSTICS.md](DIAGNOSTICS.md).
