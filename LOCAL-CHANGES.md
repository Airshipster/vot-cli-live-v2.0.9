# VOT-CLI Live v2.0.8 — озвучка видео

Доработка [fantomcheg/vot-cli-live](https://github.com/fantomcheg/vot-cli-live), основанного на [FOSWLY/vot-cli](https://github.com/FOSWLY/vot-cli) автора Toil. Цепочка: Toil / FOSWLY → fantomcheg → этот форк Airshipster. Версия **2.0.8** от **2 октября 2026 года** добавляет приоритет MP4 после выбора кодеков для каждого разрешения; предыдущие изменения включают приоритет H.264, обложку первым кадром, Microsoft Edge TTS и выбор языков. Форк может отставать от исходных проектов.

## Запуск в Windows

1. Откройте Start-VOT.cmd. Требуется PowerShell 7.
2. Выберите пункт меню и вставьте ссылку на YouTube.
3. В пункте 2 выберите исходный язык (по умолчанию — автоопределение) и язык результата.
4. Выберите озвучку, диктора Microsoft при необходимости, затем качество из вертикального списка.
5. При необходимости добавьте к номеру качества пробел и **000**: например, **4 000**, чтобы первым кадром стала обложка YouTube. Обычный ввод **4** оставляет видео без изменения кадров.

Главное меню:

    1 — Скачать видео: английский → русский
    2 — Скачать видео — выбрать другие языки
    3 — Показать справку оригинальной утилиты
    0 — Выход

Результат: **оригинальное название (Нейроперевод).mp4**, прямо на рабочем столе текущего пользователя. Недопустимые для Windows символы заменяются; при повторной загрузке добавляется номер, существующий файл сохраняется.

Путь определяется через Windows GetFolderPath('Desktop'), включая перенаправленный рабочий стол. Имя пользователя не задаётся в исходном коде. Временные файлы обрабатываются в video-jobs; после переноса результата папка задания удаляется. При ошибке сохранения готовый файл остаётся во временной папке, чтобы не потерять результат, и программа показывает его путь.

## Озвучка

1. **Яндекс — Живые голоса**: английский → русский.
2. **Яндекс — Стандартные голоса**: без аккаунта.
3. **Microsoft Edge — нейронные голоса**: без аккаунта и API-ключа, с выбором диктора для языка результата. Для русского доступны Дмитрий и Светлана; список получается с сервиса при выборе Microsoft.

Режимы Яндекса создают полную переведённую дорожку через VOT. Выбор конкретного диктора в них не предоставляется. «Живые голоса» показываются для английского → русского.

В самом браузерном VOT Microsoft (msedge) находится в настройке «Сервис перевода текста» и не меняет озвучку. В локальной программе Microsoft TTS подключён отдельно через [edge-tts](https://github.com/rany2/edge-tts).

Для Microsoft программа получает переведённые субтитры из VOT или YouTube. Если доступен только исходный текст, он переводится напрямую через Яндекс Браузер с помощью [@toil/translate](https://github.com/FOSWLY/translate), из инструментария автора VOT. Это не зависит от доступности сервера-посредника аддона. Реплики синтезируются выбранным диктором Microsoft, вставляются по временным меткам и при необходимости ускоряются, чтобы не заходить на следующую реплику. Для ролика без доступных субтитров этот движок показывает ошибку; другая озвучка не выбирается автоматически.

Живые голоса запрашиваются напрямую через протокол VOT, как в браузерном расширении: с флагом useLivelyVoice, оригинальными названием и длительностью ролика. Программа сначала делает запрос без обязательного ввода токена. Для проверенного ролика сервис вернул готовую живую озвучку без аккаунта; её аудиосигнал отличается от стандартной дорожки.

Если OAuth-токен уже задан в YANDEX_OAUTH_TOKEN, он может использоваться. Токен не записывается в исходники или журналы. Сервис может потребовать авторизацию для конкретного запроса; тогда программа показывает его отказ. Выбранные живые голоса не подменяются стандартными.

## Языки

Исходный язык: автоопределение, английский, русский, арабский, испанский, итальянский, китайский, корейский, латышский, литовский, немецкий, французский, японский. Озвучка результата: русский, английский, казахский — языки звукового перевода, поддерживаемые VOT. Список находится в src/config/languages.json и используется общим меню и CLI.

При автоопределении сначала используются язык видео и оригинальной аудиодорожки YouTube, затем язык исходных автоматических субтитров. Если YouTube не сообщает язык, запрос передаётся в VOT с auto. Английский принудительно не подставляется. Список подтверждён [документацией VOT](https://github.com/ilyhalight/voice-over-translation/blob/master/LANG_SUPPORT.md); доступность конкретной языковой пары определяется сервисом.

## Качество и звук

Список получен для выбранного ролика через yt-dlp. Для каждого размера кадра (ширина × высота) сначала остаются только **H.264**, если такие варианты доступны; иначе остаются **все доступные кодеки**. Затем среди оставшихся вариантов этого размера показываются только **MP4**, если они есть; иначе показываются остальные исходные контейнеры. WEBM скрывается, когда после выбора кодеков есть MP4 того же размера. Ограничения высоты нет: 1440p/2160p доступны в VP9/AV1, если H.264 для них не предлагается. В пределах этих фильтров доступны разные FPS и способы доставки. Варианты упорядочены по разрешению, FPS и заявленному битрейту. Размер изображения показан всегда; FPS, битрейт, кодек и контейнер — при различиях между вариантами. Метка [число] — идентификатор формата yt-dlp. Номера пунктов могут меняться: сравнивайте свойства и идентификатор формата, а не только номер выбора.

Размер в меню — известный размер исходного видеопотока, без будущей озвучки. Метка **HLS*** у битрейта означает скорость из HLS-манифеста, а не измеренный средний битрейт. Большая цифра у HLS не гарантирует более качественное изображение или больший файл: HLS и HTTPS могут содержать одинаковые кадры, отличаясь упаковкой.

Для форматов без звука оригинальная аудиодорожка скачивается отдельно и объединяется с видео. Итог — MP4 с выбранным видеопотоком без перекодирования и звуком AAC. Показанный контейнер относится к источнику: например, WEBM/VP9 перепаковывается в MP4/VP9. Оригинальный звук снижается до **15%**, перевод добавляется с громкостью **100%**. Автоматическая нормализация отключена, чтобы не повышать заданную громкость фона.

### Обложка на первом кадре

Ввод **4 000** выбирает четвёртое качество и заменяет только самый первый кадр обложкой этого видео с YouTube. Изображение вписывается без растяжения, при необходимости с чёрными полями. Разрешение, частота кадров, длительность и начало звука сохраняются. Всё видео в этом режиме перекодируется через libx264, preset veryfast, CRF 18; обработка занимает больше времени, а файл может существенно вырасти. Увеличение зависит от исходного сжатия и нового кодирования, а не только от добавленного изображения. Без 000 выбранный видеопоток копируется.

Скачанная обложка используется во временной папке задания и затем удаляется. Ошибка получения обложки показывается пользователю; запрошенная обложка не пропускается молча.

Первый кадр не гарантирует автоматический выбор этой картинки при загрузке на YouTube. Для точного результата [загрузите собственную миниатюру в YouTube Studio](https://support.google.com/youtube/answer/72431?hl=ru).

## Прогресс

Скачивание перевода, видео и оригинального звука, затем сведение озвучки показывают процент текущего этапа в конце строки. В интерактивном окне строка обновляется на месте; при сохранении вывода в журнал остаются отдельные строки. Время до завершения — приблизительная оценка. Для скачивания процент вычисляется по полученным байтам или фрагментам; для сведения — по обработанной длительности видео. 100% показывается после завершения этапа. Перевод не скачивается повторно перед сведением.

Во время подготовки дорожки Яндекс не предоставляет процент готовности: выводится прошедшее время и оценка оставшегося времени сервиса, если она есть.

Для Microsoft процент синтеза вычисляется по числу готовых блоков реплик; 100% появляется после записи полной дорожки. Время до завершения оценивается по темпу обработки.

## Компоненты

При запуске проверяются Node.js, yt-dlp, FFmpeg и npm-зависимости. Недостающие компоненты скачиваются в папку программы; более старые версии обновляются до проверенного набора. Загрузка бинарников проверяется по SHA-256. Системная политика выполнения PowerShell не изменяется.

Проверенный набор: Node.js не ниже 22.19; @vot.js/node 3.1.4; @toil/translate 1.10.0; yt-dlp 2026.08.19; FFmpeg 9.0.2. Переход на произвольные непроверенные новые версии не выполняется.

При выборе Microsoft дополнительно проверяются Python (не ниже 3.12) и edge-tts 7.2.8. Python берётся из установленного набора или скачивается в папку программы с официального python.org с проверкой SHA-256. Python-пакеты устанавливаются локально в edge-packages, системные пакеты не заменяются.

## Командная строка

Интерактивный запуск:

    pwsh -NoProfile -File .\Run-VOT.ps1

Пример с заглушкой VIDEO_ID и живыми голосами:

    pwsh -NoProfile -File .\Run-VOT.ps1 -VideoUrl 'https://www.youtube.com/watch?v=VIDEO_ID' -Once -VoiceStyle live -MaxHeight 1080

Для точного выбора формата используйте -VideoFormatId с идентификатором из списка. Обычный интерактивный запуск не имеет ограничения высоты.

Чтобы сделать обложку первым кадром при запуске с аргументами, добавьте **-ThumbnailFirstFrame**. Низкоуровневый CLI принимает **--thumbnail-url** с HTTPS-ссылкой на изображение вместе с **--merge-video**.

Пример с автоопределением и Microsoft:

    pwsh -NoProfile -File .\Run-VOT.ps1 -VideoUrl 'https://www.youtube.com/watch?v=VIDEO_ID' -Once -SourceLanguage auto -TargetLanguage ru -VoiceStyle edge -TtsVoice ru-RU-SvetlanaNeural -MaxHeight 1080

## Доступность перевода

Программа ждёт полную дорожку и ограниченно повторяет временные отказы Яндекса. Доступность конкретного перевода определяет сервис. Прежний HTTP 400 не доказывает ошибку установленной версии SDK: после готовности перевода старый и новый SDK получали результат.
