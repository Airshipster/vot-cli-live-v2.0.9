# Подготовка изменений к публикации

1. Обновите `package.json`, корень `package-lock.json` и его запись `packages[""]` согласованной версией. Опишите изменения в README и LOCAL-CHANGES.
2. Проверьте синтаксис Node.js/PowerShell и относящиеся к изменению сценарии. Работа внешних сервисов проверяется отдельно от синтаксиса.
3. Сверьте список файлов с `.gitignore` и [PRIVACY.md](PRIVACY.md). Не добавляйте сессии, секреты, очереди, журналы, медиа, зависимости или данные своего профиля.
4. Добавляйте проверенные исходники и документацию по явному списку. Просмотрите staged diff, затем создайте коммит и отправьте его в согласованную ветку без force push.
5. После публикации проверьте удалённый SHA, README и версию. Публикация npm-пакета и создание GitHub Release — отдельные действия; обновление Git-ветки само по себе их не выполняет.
